# JavaScript for Cybersecurity

JavaScript fundamentals focused on cybersecurity and web security.

## Topics

- JavaScript Basics
- Variables & Data Types
- Functions
- Arrays & Objects
- DOM
- Events
- Fetch & HTTP Requests
- JSON
- Cookies & Local Storage
- Async / Await

## Goal

Learn enough JavaScript to understand, analyze and interact with JavaScript-based web applications from a cybersecurity perspective.
